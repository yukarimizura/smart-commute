# 🚦 Smart Commute DSS (Decision Support System)

Sistem Pendukung Keputusan Mobilitas Mahasiswa berbasis topologi jalan asli (OSRM/TomTom), satelit cuaca langsung (Open-Meteo), dan optimasi waktu keberangkatan dengan evaluasi multi-kriteria (waktu tempuh, risiko keterlambatan, jejak karbon CO₂, dan paparan polutan PM2.5).

---

## 🛠️ Tech Stack
- **Backend:** FastAPI (Python 3.10+), Uvicorn, HTTPX, Pydantic, python-dotenv
- **Frontend:** React, Vite, Tailwind CSS, Leaflet / React-Leaflet
- **Data & Telemetri:** TomTom Traffic API, OSRM, Open-Meteo Weather API, Nominatim OpenStreetMap
